# GGG (GoGoaGone)

Terminal animations but I use it as Screen idle animations for Hyprland, triggered via [hypridle](https://wiki.hypr.land/Hypr-Ecosystem/hypridle/). Named after the cult classic Indian zombie comedy [Go Goa Gone](https://www.imdb.com/title/tt2436516/) because i use these animations when i am _**GONE**_.

## Animations

- **matrix** - Matrix-style digital rain (cmatrix vibes)
- **plasma** - Plasma wave interference patterns
- **spiral** - Rotating spiral galaxy
- **fire** - Realistic fire simulation (WIP)
- **julia** - Animated Julia set fractal
- **voronoi** - Bunch of colored blobs
- **lorenz** - Lorenz attractor (chaos theory)
